# codex-praedium
Open-source governance standards and best practices for state-level AI regulation in real estate, built around licensee-in-the-loop oversight, fiduciary compliance, and broker supervision.

# purpose

Codex Praedium provides reference architectures, compliance guardrails, and operational standards for building AI tools in the real estate industry. Focused on state-level regulatory compliance, it helps engineering and brokerage teams enforce licensee-in-the-loop verification, auditability, and statutory supervision across AI-assisted transactions.
