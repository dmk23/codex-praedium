## Key Policy Takeaways Across Publications

| Core Theme | Summary of Findings |
| :--- | :--- |
| **State vs. Federal Jurisdiction** | Real estate licensure and fiduciary duties are governed exclusively at the state level; federal preemption efforts weaken local consumer enforcement. |
| **Low-Hanging Fruit vs. Systemic Risk** | Policing virtual staging photos among licensed agents is an easy distraction; the deeper threat is unlicensed software entities conducting end-to-end transactions for fees. |
| **Probabilistic Limits of AI** | Generative models guess token sequences and suffer from context deterioration, making pre-execution human licensee verification mandatory for binding contracts. |
| **Non-Delegable Supervision** | Brokerage supervision rules must evolve for an AI-first environment so managing brokers cannot use "thin broker" structures to rubber-stamp unmonitored bots. |
